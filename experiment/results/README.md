# Accepted experiment results

Create one dated directory per accepted run only after its configuration was
selected without consulting the independent test set. Commit compact artifacts
such as metrics, configuration, provenance, and the executed notebook. Keep
large checkpoints and prediction arrays in Google Drive and record their hashes
and Drive locations in the result README.

The suggested directory name is `YYYY-MM-DD-model-seed`, for example
`2026-07-22-ubifusion-v1-seed42`.
